# Stickers, Magnets & Custom Shirts

A public shop page where customers order stickers, magnets, and custom shirts. Orders come in by text or email — nothing is charged on the page itself. PayPal and Cash App pay buttons are on the page.

## How changes work

This page is built and published by Ziggy, the owner's assistant. If you're an AI helping with the layout or design, suggest changes as updated code or clear edit instructions, and send them to the owner — he forwards them to Ziggy for review. Only Ziggy puts changes live.

Don't change prices, the pay buttons, or how ordering works unless the owner asks.

## Files

- `index.html` — the whole shop page in one file, design catalog included. Design pictures load from the owner's live-streaming site.
