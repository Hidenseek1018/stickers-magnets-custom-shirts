# Stickers, Magnets & Custom Shirts

Public shop page for Nicholas's sticker, magnet, and custom shirt business. Customers browse designs and order by text or email — nothing is charged on the page itself.

Current version: v55 (waterproof stickers).

## What the shop sells

- Stickers (regular + waterproof), 2–7 in
- Magnets, 3–6 in
- Custom shirts, design width up to 9 in
- Trio bundles (sticker + magnet + shirt)

Prices, discounts, and shipping are set in the page — see the prices section in `index.html`. Do not change them unless the owner asks.

## How ordering works

The customer picks a design, chooses a product and size, and places the order — it opens their text app with the order ready to send to the owner (email is the fallback). The owner confirms each order by message. PayPal and Cash App pay buttons are on the page with the order total pre-filled.

## How changes work

This page is built and published by Ziggy, the owner's assistant. If you're an AI helping (Copilot, Grok, Claude, or any other), suggest changes as updated code or clear edit instructions, and send them to the owner — he forwards them to Ziggy for review. Only Ziggy puts changes live.

Don't change prices, the pay buttons, shipping, or how ordering works unless the owner asks.
